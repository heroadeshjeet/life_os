# Background Music

## Subfolders

- `exercise/` — uplifting, energizing tracks for workouts (120–145 BPM)
- `meditation/` — calm, ambient, nature sounds for meditation
- `focus/` — brain-wave entrainment / binaural beats for deep focus

## Format

- MP3, 192 kbps, stereo
- Seamlessly loopable (no silence at start/end)
- 3–6 min for exercise, 5–15 min for meditation, 10–30 min for focus

## Naming

- Exercise: `uplifting-1.mp3`, `steady-push-1.mp3`, `high-energy-1.mp3`
- Meditation: `calm-1.mp3`, `nature-rain.mp3`, `singing-bowls.mp3`
- Focus: `brain-waves-alpha.mp3`, `binaural-focus.mp3`

See `/ASSETS_NEEDED.md` section 4 for full details.
